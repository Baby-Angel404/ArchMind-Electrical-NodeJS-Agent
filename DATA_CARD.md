# Dataset Card: ArchMind Electrical Telemetry Stream

## 1. Dataset Summary
Dataset telemetri listrik frekuensi tinggi dari node pemantau berbasis ESP32, SCT-013-000 Current Transformer, dan ZMPT101B Voltage Transducer. Mencakup data continuous 50Hz AC mains, fluktuasi transien beban, anomali termal, dan sag/swell voltage untuk pelatihan model AI dan predictive maintenance.

```mermaid
flowchart LR
    A[Mains 230V AC / 30A Load] -->|Sampling 5s / 1kHz ADC| B[ESP32 Node]
    B -->|MQTT TLS| C[Ingest Pipeline]
    C --> D[(TimescaleDB / InfluxDB)]
    D --> E[Dataset: 50,000+ Records]
```

---

## 2. Dataset Structure & Fields

| Field | Type | Unit | Range Valid | Deskripsi |
|---|---|---|---|---|
| `deviceId` | string | - | - | Pengenal unik hardware node (contoh: `esp32-node-001`) |
| `timestamp` | string | ISO 8601 | UTC | Timestamp presisi milidetik dari hardware RTC/SNTP |
| `voltage` | float | V RMS | 180.0 – 260.0 | Tegangan jala-jala efektif AC 50 Hz |
| `current` | float | A RMS | 0.0 – 30.0 | Arus beban terukur via SCT-013-000 |
| `power` | float | Watts | 0.0 – 7200.0 | Daya aktif terhitung: $P = V \times I \times PF$ |
| `temperature` | float | °C | -20.0 – 85.0 | Suhu sensor & junction enclosure |
| `frequency` | float | Hz | 49.5 – 50.5 | Frekuensi fundamental jala-jala listrik |
| `powerFactor` | float | - | 0.70 – 1.00 | Faktor daya beban (induktif/resistif) |
| `anomalyLabel` | int | - | 0, 1, 2 | 0 = Normal, 1 = Voltage Sag/Swell, 2 = Overheat |

### Sample Record (JSON)

## 3. Distribusi & Statistik Kunci

- **Volume Data**: 50.000+ observasi terlabel.
- **Rasio Anomali**: 94% Normal, 4% Voltage Fluctuation (Sag/Swell), 2% Thermal Drift (>70°C).
- **Sampling Cadence**: 5.0 detik continuous stream.
- **Toleransi Pengukuran**: Voltage $\pm 0.5\%$, Current $\pm 1.0\%$, Temperature $\pm 0.5^\circ\text{C}$.

## 4. Cara Penggunaan (Python / Pandas)

```python
import pandas as pd
import json

# Load dataset
df = pd.read_json("telemetry_stream.json")

# Filter anomali tegangan di luar toleransi PLN/IEC (+10% / -10%)
anomalies = df[(df["voltage"] > 253.0) | (df["voltage"] < 207.0)]
print(f"Total over/under voltage events: {len(anomalies)}")

# Hitung konsumsi energi harian (kWh)
df["energy_kwh"] = (df["power"] * 5) / (3600 * 1000)
total_kwh = df["energy_kwh"].sum()
print(f"Total Energy: {total_kwh:.3f} kWh")
```

## 5. Sumber & Integritas Data
- **Hardware Generation**: Divalidasi via ESP32 FreeRTOS firmware (`CODE_SCAFFOLDING/firmware`).
- **Verifikasi Skema**: Sinkron 100% dengan NestJS DTO validator (`backend-nodejs`) dan schema C++ `telemetry_contract.h`.
- **Standar Rujukan**: IEC 61010-1 (Safety requirements for electrical equipment) & IEC 62053-21 (Static meters for AC active energy).
